## Deskripsi
Halaman Profil Mahasiswa merupakan tugas praktikum Desain Web yang dibuat menggunakan HTML dasar. Halaman ini berisi informasi identitas mahasiswa, minat belajar, informasi singkat, target belajar, dan karakter khusus HTML.

## Elemen HTML yang Digunakan
1. `<h1>`, `<h2>`, dan `<h3>` untuk judul dan subjudul.
2. `<p>` untuk membuat paragraf.
3. `<strong>` dan `<b>` untuk menebalkan teks.
4. `<em>` untuk memberikan penekanan pada teks.
5. `<u>` untuk memberikan garis bawah pada teks.
6. `<br>` untuk membuat baris baru.
7. `&lt;` dan `&gt;` untuk menampilkan karakter khusus HTML.
8. `&copy;` untuk menampilkan simbol hak cipta.
