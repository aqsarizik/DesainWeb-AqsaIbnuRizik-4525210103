## Elemen HTML yang Digunakan

1. Struktur HTML: Menggunakan tag "html", "head", dan "body".
2. Heading: Menggunakan tag "h1" dan "h2" untuk judul dan subjudul.
3. Paragraf: Menggunakan tag "p" untuk menampilkan informasi.
4. Tautan: Menggunakan tag "a" untuk navigasi dan menghubungkan ke website Universitas Pancasila.
5. Gambar: Menggunakan tag "img" untuk menampilkan logo organisasi kampus.
6. Daftar: Menggunakan tag "ul" dan "li" untuk menampilkan daftar kegiatan.
7. Navigasi: Menggunakan tag "nav" untuk berpindah ke bagian halaman.
