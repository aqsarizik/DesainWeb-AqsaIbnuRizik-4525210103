## 3. Perubahan yang Dilakukan
- Memindahkan aturan CSS dari atribut `style` dan tag `<style>` di HTML ke file CSS terpisah.
- Menggunakan `box-sizing: border-box` agar perhitungan ukuran elemen lebih konsisten.
- Membuat class yang dapat digunakan kembali, seperti `.container`, `.card`, dan `.btn`.
- Menggunakan variabel CSS untuk warna, radius, dan jarak agar pengaturan desain lebih mudah.
- Mengganti tata letak berbasis `float` dengan CSS Grid pada bagian layanan.
- Menggunakan Flexbox untuk merapikan posisi header dan navigasi.
- Menambahkan meta viewport agar halaman dapat menyesuaikan ukuran layar perangkat.
- Menambahkan media query untuk mengatur ukuran judul, jarak, navigasi, dan card pada perangkat seluler.
