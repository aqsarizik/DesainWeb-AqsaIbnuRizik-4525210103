### Website Dapur Betawi
## 1. Deskripsi
Dapur Betawi adalah website sederhana bertema restoran yang memperkenalkan masakan khas Jakarta. Website ini menampilkan informasi restoran, keunggulan layanan, daftar menu beserta harga, dan bagian reservasi. 

## 2. Tujuan
- Memperkenalkan restoran dan masakan khas Betawi.
- Menampilkan menu makanan dan harga dengan jelas.
- Memudahkan pengunjung berpindah ke bagian Beranda, Tentang, Menu, dan Kontak melalui navigasi.
- Menyediakan tautan reservasi melalui email.

## 3. Teknologi yang Digunakan
- HTML5 untuk menyusun struktur dan konten halaman.
- CSS3 untuk mengatur tampilan, warna, tata letak, tombol, kartu menu, dan responsivitas.
- Gambar lokal sebagai ilustrasi ruang makan dan makanan.

## 4. Fitur Website
1. Beranda — menampilkan pengenalan Dapur Betawi dan tombol menuju menu atau reservasi.
2. Tentang Kami — menjelaskan keunggulan restoran, yaitu bahan segar, resep tradisional, dan suasana nyaman.
3. Menu Favorit — menampilkan Ketoprak (Rp25.000), Nasi Uduk (Rp32.000), dan Bubur Ayam (Rp22.000).
4. Reservasi — menyediakan tautan email untuk menghubungi restoran.
5. Navigasi — tautan menu mengarah ke bagian terkait pada halaman yang sama.
6. Desain responsif — tata letak menyesuaikan ukuran layar desktop, tablet, dan ponsel melalui media query CSS.

## 6. Cara Menjalankan
1. Unduh atau ekstrak folder proyek.
2. Pastikan file index.html, folder CSS, dan folder images tetap berada pada struktur yang sama.
3. Buka file index.html menggunakan browser seperti Google Chrome.
4. Klik menu navigasi untuk melihat bagian Beranda, Tentang, Menu, dan Kontak.

## 7. Penjelasan File
- index.html: berisi struktur halaman, teks, navigasi, daftar menu, gambar, dan tautan reservasi.
- CSS/style.css: berisi aturan tampilan seperti warna, tipografi, jarak, grid, tombol, serta pengaturan responsif.
- images/: menyimpan aset gambar yang digunakan pada halaman website.

## 8. Kesimpulan
Website Dapur Betawi merupakan contoh website restoran sederhana yang dibuat menggunakan HTML dan CSS. Website ini menyajikan informasi restoran dan menu secara terstruktur, serta memiliki tampilan responsif agar lebih nyaman diakses melalui berbagai ukuran layar.
